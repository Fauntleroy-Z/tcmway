> 独立于文章内容。文章漫画不动，这里专门做推广。

## 目录结构

```
images/ollie-promo/
├── README.md          ← 本文件
├── wallpapers/        ← 桌面/手机壁纸
├── stickers/          ← 贴纸素材（待生成）
├── expressions/       ← Ollie 表情包 8 变体（天昊生成中）
└── social-media/      ← 社交平台用图（头像/banner/帖子图）
```

## 与文章的边界

| 在哪里 | 用途 | 目录 | 是否可改 |
|--------|------|------|----------|
| 文章页 `posts/*.html` | 文章配图漫画 | `images/comic-*-v4.png` | ❌ 不动 |
| 文章页 Ollie 头像 | 品牌标志 | `images/ollie-warm-v3.png` | ❌ 不动 |
| 文章页小头像 | 品牌标志 | `images/ollie-mini-v3.png` | ❌ 不动 |
| 壁纸下载 | 推广 | `images/ollie-promo/wallpapers/` | ✅ 随时迭代 |
| 表情包 | 推广/贴纸 | `images/ollie-promo/expressions/` | ✅ 天昊生成中 |
| 贴纸 | 推广/周边 | `images/ollie-promo/stickers/` | ✅ 待设计 |

## Ollie 品牌基准

- **物种**：Screech Owl (*Megascops asio*)，有耳羽簇
- **头部**：#b83a2a 朱红
- **面部/肚皮**：#e8a87c 杏色
- **吊坠/虹膜**：#c9a84c 金色
- **嘴**：短弯钩喙 #b83a2a + 金色 accent 线
- **背景**：#fdf6ee 暖奶油
- **风格**：温暖手绘插图，径向渐变 + 柔影，非扁平矢量
