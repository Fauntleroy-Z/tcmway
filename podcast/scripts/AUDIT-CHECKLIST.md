# 播客质检清单 (for Tianhao)

> 每次巡检 tcmway-blog 时同步检查。最终脚本在 `podcast/scripts/`，线上音频在 `podcast/ep0*.mp3`。

## 每次必查

### 1. 预告一致性
- [ ] Ep01 结尾 "Next time..." 段 → 描述的必须是 Ep02 实际主题
- [ ] Ep02 结尾 "Next time..." 段 → 描述的必须是 Ep03 实际主题
- [ ] 每集预告内容与下一集脚本开头内容能对上

### 2. RSS feed 准确性
- [ ] `podcast/feed.xml` 中每集 `<title>` 与脚本主题一致
- [ ] `<itunes:summary>` 与脚本内容一致
- [ ] `<enclosure length>` 与实际 mp3 文件大小一致
- [ ] `<itunes:duration>` 与实际音频时长一致

### 3. 博客联动
- [ ] 每集播客有对应博客文章（主题相同）
- [ ] RSS `rss.xml` 中最新文章标题/简介与实际文章一致

### 4. 音频质量
- [ ] 片头：古琴独奏 12 秒 → 完全淡出 → 人声进入（不重叠）
- [ ] 片尾：人声结束 → 5 秒音乐淡出
- [ ] 时长：每集 17-21 分钟

### 5. 脚本质量
- [ ] 中文术语 ≤ 3 个/集
- [ ] 每集约 2800-3500 词
- [ ] 无 AI 高频过渡句（"It's worth noting that...", "In conclusion..." 等）
- [ ] 预告段的语气和前文一致
