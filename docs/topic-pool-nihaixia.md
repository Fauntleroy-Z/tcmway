## 📌 倪海厦是谁（速查）

- **1954年生于台湾，2012年去世**。经方派代表人物
- 被誉为"命、相、卜、山、医"五术兼备之旷世奇人
- **著作体系**：
  - 《天纪》：易经、命理、风水（已完成）
  - 《人纪》：黄帝内经(94集) / 神农本草经(70集) / 伤寒论(69集) / 金匮要略（已完成）
  - 《地纪》：未完成即去世
- **教学特色**：从患者症状出发回溯经典（反转传统教学顺序）
- **核心理念**：阳气为本、经方思维、肝主疏泄、中医是科学方法

## 📝 选题原则

1. **每个选题必须能独立成篇**——不要求读者读过其他文章
2. **西方视角优先**——用类比/生活场景引入，避免术语堆砌
3. **Ollie IP贯穿**——每篇配四格漫画（脚本先于正文）
4. **懒兔子风格**——轻松幽默接地气，不端着不贩卖焦虑
5. **禁止词清单**：essays/academic/scholarly/comprehensive/treatise/lecture
6. **自评<9分必须重写**
