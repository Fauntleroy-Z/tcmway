> 版本：v1.0 | 创建：2026-06-01 | 由天昊整理
> 基于已发11篇文章的实践模式提炼 + 5阶段流程 + 8维评分

---

## 一、5阶段工作流程

### Phase 1 — 选题审查（必须执行，禁止跳过）
- [ ] 检查选题池映射表，确认不与已发布文章大面积重叠
- [ ] 如选题为已发文章的"进阶版"（如T3是#04的进阶），须明确区分角度
- [ ] 确认选题在Tier 1优先（高共鸣+高实用），除非主人另有指定
- [ ] 检查 `.topic-pool.md` 和 `topic-pool-nihaixia.md` 知识储备
- [ ] **内容查重**：逐一检查已发布文章，确认不重复以下内容：
  - 相同的开篇场景/个人体验故事
  - 相同的类比/比喻（如已用"交通堵塞"比喻气滞，新文章不再用）
  - 相同的案例/示例（如已用"咖啡提神"举例，新文章换场景）
  - 相同的金句/收尾方式
  - 相同的关键概念展开角度（即使讲同一概念，必须换切入点）

### Phase 2 — 漫画脚本（先于正文）
- [ ] 写4格漫画脚本（Ollie猫头鹰IP贯穿）
- [ ] 风格：2D扁平手绘，详见 **三-A Ollie IP 视觉一致性**
- [ ] 拒绝"可爱"风格，保持温暖智慧
- [ ] 漫画脚本文件：`docs/comic-scripts/article-XX-script.md`
- [ ] 漫画生成后保存为 `images/comic-XX-title-new.png`

### Phase 3 — 正文起草
- [ ] 开篇：个人体验/生活场景切入（窦文涛式"不装"）
- [ ] 主体：1个核心概念 + 2-3个具象类比 → 1-2个实用建议
- [ ] 结尾：金句收尾，"放下"而非"记住"
- [ ] 遵循 Ollie 表达方法论（见 `.topic-pool.md` 第四节）
- [ ] 禁止词：essays/academic/scholarly/comprehensive/treatise/lecture

### Phase 4 — 8维自评
- [ ] 逐项打分（见下方评分表）
- [ ] 总分≥9.0 → 通过；<9.0 → 回到Phase 3重写
- [ ] 评分记录写入当日工作日志

### Phase 5 — HTML发布
- [ ] **风格统一自检**：对照第三章 A/B/C/D 四表逐项过，全部通过才继续
- [ ] 创建 `posts/XX-slug.html`
- [ ] 更新 `index.html` 文章列表
- [ ] 确保 og:image 指向漫画图片
- [ ] 包含百度统计代码
- [ ] FAQ结构化数据（JSON-LD）

## 二、8维评分标准（阈值9.0）

| 维度 | 权重 | 评分标准 | 满分描述 |
|------|:---:|---------|---------|
| 1. 内容准确性 | 20% | TCM概念无硬伤，引用经典有据 | 经得起中医专业读者审视 |
| 2. 英文流畅度 | 20% | 母语级自然表达，无翻译腔 | 英语读者不会觉得"这是翻译的" |
| 3. 可读性/趣味性 | 15% | Ollie语气贯穿，类比生动 | 读完全文不费力，想分享 |
| 4. 西方读者适配 | 15% | 类比来自西方生活经验，术语极少 | 不需要中国文化背景就能懂 |
| 5. SEO友好度 | 10% | 标题含搜索意图关键词，meta完整 | 标题能独立引流 |
| 6. 结构逻辑 | 10% | 开篇→展开→收尾，过渡自然 | 读完有"完整感" |
| 7. 差异化/独特价值 | 5% | 不与已有文章重复，有独特角度 | 读者觉得"这个角度没听过" |
| 8. 漫画匹配度 | 5% | 漫画准确传达核心概念，风格一致 | 图文互相增强 |

**计算公式**：总分 = Σ(维度得分 × 权重)

**自评要求**：每写完正文必须逐项打分，低于9.0必须重写。评分记录写入工作日志。

## 三、风格统一检查清单（每条发布前必查）

### A. Ollie IP 视觉一致性

| 检查项 | 标准 | 禁止 |
|:---|:---|:---|
| 头部颜色 | 朱砂红 `#b83a2a` | 偏橙、偏粉、偏暗 |
| 腹部颜色 | 杏色 `#e8a87c` | 纯白、纯黄、过饱和 |
| 耳羽簇 | 头顶两侧尖角羽簇，必须画出 | 圆头无耳羽 |
| 眼睛 | 大圆眼，温暖智慧神采 | 凶、呆、过萌、半闭 |
| 喙 | 短三角喙 | 长喙、弯钩喙 |
| 吊坠 | 金阴阳吊坠 `#d4a017`，胸前悬挂 | 无吊坠、颜色不对 |
| 画风 | 2D扁平手绘，干净线条 | 3D、渐变、水彩、像素 |
| 气质 | 温暖智慧，反可爱 | cute mascot、卡通夸张 |
| 姿态 | 自然放松，不僵硬 | 翅膀张开过度、过于戏剧化 |

### B. Ollie 文风一致性

| 检查项 | 标准 | 禁止 |
|:---|:---|:---|
| 开篇方式 | 个人体验/生活场景切入 | 直接讲概念、教科书式定义 |
| 语气 | 轻松、谦逊、自嘲（"I might be wrong..."） | 说教、权威、贩卖焦虑 |
| 类比来源 | 西方日常生活（咖啡/堵车/手机） | 仅中式典故、生僻文化梗 |
| 信息密度 | 1个核心概念 per 篇 | 堆砌多个概念、百科全书式 |
| 结尾 | 金句收尾，"放下"而非"记住" | 结论式、命令式 |
| 字数 | 1500-2200 words | 短于1200或超2800 |
| 标题格式 | 悬念/问题/反差式，含搜索关键词 | 平淡陈述句、纯中文 |
| 倪海厦 | 仅出现在 Sources 区域 | 正文出现名字（用"classical physicians"替代） |
| 禁词 | — | essays / academic / scholarly / comprehensive / treatise / lecture / mysterious / magic(magical) |

### C. 文章结构一致性

| 检查项 | 标准 |
|:---|:---|
| Ollie speaks 板块 | 每篇1个（对话气泡 + ollie-warm.svg） |
| 漫画嵌入 | img标签引用 images/comic-XX-*.png |
| FAQ Schema | JSON-LD，3-4组 Q&A |
| Meta description | 140-160字，含搜索意图关键词 |
| OG image | 指向该篇漫画图片 |
| Sources 区域 | `<section class="sources">`，列出经典引用 |
| Ollie 签名 | `&mdash; Ollie` 结尾 |

### D. 跨文章一致性

| 检查项 | 标准 |
|:---|:---|
| 类比/比喻 | 不与已发文章重复（查重清单见 Phase 1） |
| 概念衔接 | 如引用前文概念，加链接 `→ <a href="...">read more</a>` |
| 漫画风格 | 所有漫画视觉风格一致（按A表自检） |
| Ollie 口吻 | 15篇文章读起来像同一个人（鸟）写的 |

## 四、铁律（永久生效）

1. **漫画先行**：先定漫画脚本再写正文，确保文章有视觉锚点
2. **Ollie IP贯穿**：每篇文章Ollie必须出场（至少漫画中）
3. **漫画原图禁止处理**：AI生成的漫画PNG直接使用，不做二次编辑
4. **反可爱**：Ollie是智慧温暖的猫头鹰，不是cute mascot
5. **懒兔子风格**：轻松幽默接地气，不端着不贩卖焦虑
6. **自评<9分必须重写**
7. **发布前主人审阅**：HTML完成后先给主人预览，批准后推送
8. **发布后写工作日志**：记录选题、评分、经验教训
