# TCM Way 选题池

> 策略：60% 系列推进 + 20% 读者问题 + 10% 节气/时事 + 10% 灵感挖掘
> 每天 AI 自动选题，主人回来看网站结果，有想法隔天指示修改。

---

## 选题决策算法（CEO 每日执行）

1. **排除已发布**（published.md 中的题目）
2. **优先时间敏感**（seasonal.md 中当天 ±3 天的节气/节日）
3. **检查系列连续性**（上一个系列的下一篇）
4. **多样性检查**（连续 3 天不写同一支柱）
5. **从 pipeline 中取优先级最高的**
